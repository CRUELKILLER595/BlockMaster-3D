# 🎮 BlockMaster 3D

**BlockMaster 3D** is a 3D platformer developed using Unity and C#. Jump across platforms, dodge enemies, collect coins, and use powerful abilities to overcome challenging levels!

## ✨ Features

- **Multiple Levels** — Progress through increasingly challenging platforming levels.
- **Coin Collection** — Collect coins and increase your score.
- **Enemies & Hazards** — Avoid dangerous enemies and environmental obstacles.
- **Power-Ups** — Discover special abilities to help you survive.
- **Score System** — Track your performance and compete against your personal best.
- **Level Progression** — Unlock new challenges as you complete levels.
- **3D Gameplay** — Test your reflexes, precision, and timing.

## 🛠️ Built With

- **Game Engine:** Unity 6
- **Programming Language:** C#
- **Version Control:** Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Unity Hub
- A compatible Unity Editor version
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the cloned project folder.
4. Open the project using the appropriate Unity Editor version.
5. Open the game's title scene and press **Play**.

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

## 🎯 How to Play

Jump across platforms, avoid enemies, collect coins, and use power-ups strategically to overcome each level. Improve your score and see how far you can progress!

*Refer to the in-game instructions for the current control scheme.*
